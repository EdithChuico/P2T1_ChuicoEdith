## P2T1_ChuicoEdith - Programación Funcional e Interfaces en Java

Este repositorio contiene la resolución de la Tarea 1, enfocada en la aplicación práctica de la programación funcional en Java, el uso de expresiones lambda, interfaces funcionales y la composición de funciones.

### Tecnologías y Herramientas
* **Lenguaje:** Java 17 (o superior)
* **Gestor de dependencias:** Maven
* **Paradigma:** Orientado a Objetos y Funcional

### Estructura del Proyecto
El proyecto está dividido en paquetes separados según las actividades solicitadas:
* `org.example.actividad2`: Refactorización de código heredado (OOP) hacia un estilo funcional usando `Predicate` y `Function`.
* `org.example.actividad3`: Creación y uso de una interfaz funcional propia (`@FunctionalInterface`) para el cálculo de tributos (IVA, Retención, etc.).
* `org.example.actividad4`: Composición de funciones utilizando los métodos `andThen()` y `compose()` para la transformación de cadenas de texto.

### Instrucciones de Compilación y Ejecución

Al ser un proyecto gestionado con Maven, se lo puede ejecutar utilizando cualquier IDE como Apache NetBeans, IntelliJ IDEA o Visual Studio.

1. Descargar el repositorio como ZIP.
2. Abrir el proyecto en el IDE seleccionado.
3. Esperar que el IDE descargue las dependencias de Maven.
4. Ir hacia cualquiera de las clases principales (`ProcesadorOOP.java`, `MainTributos.java` o `ComposicionNombres.java`), y seleccionar **Run File** (Para ejecutar el archivo).
